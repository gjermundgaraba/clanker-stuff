# Venn / set overlap

Membership and intersections.

Overlaps mean shared membership, disjoint regions mean exclusivity, and containment means subset. Label intersections explicitly when they carry the point. A schematic Venn need not have proportional areas: label it as conceptual when counts are shown without calibrated geometry. Quantitative set diagrams must reconcile set and intersection counts and use an area-fitting method; casually resizing circles cannot ensure all overlaps are correct. For many sets or precise intersection comparisons, use a membership/intersection table rather than an unreadable tangle.
