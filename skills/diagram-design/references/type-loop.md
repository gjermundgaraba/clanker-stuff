# Loop / cycle

Recurring stages and feedback.

Arrange stages around a ring with directional connections and an explicit cycle closure. Label the recurrence or feedback mechanism so circular placement does not invent one. For `N` positions, `theta_i=start+2*pi*i/N`, `x_i=cx+rx*cos(theta_i)`, `y_i=cy+ry*sin(theta_i)`. Unequal node widths may need adjusted angular spacing; spacing does not encode duration unless stated. Open the loop or mark an exit if the process can terminate. Distinguish a feedback edge from the main cycle when their meanings differ.
