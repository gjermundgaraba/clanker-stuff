# Layer stack

Ordered abstraction or precedence.

Use stacked bands for actual abstraction levels, protocol layers, or precedence. State which direction means higher abstraction, priority, or data movement. Bands can have equal heights unless size is explicitly quantitative. Preserve named levels and explain omitted layers. Cross-layer dependencies are edges or annotations; vertical adjacency alone does not define a call path. Unordered categories belong in a matrix or architecture layout.
