# Flowchart

Decisions and control flow.

Use action boxes for work, diamonds for decisions, and distinct start/end markers. Every decision's outgoing edges carry mutually understandable guards such as yes/no or explicit cases; name fallbacks and termination where relevant. Branches may rejoin, and loops need an identifiable return path. Arrow direction describes control transfer, not ownership. Reserve space around a diamond for labels and keep retry paths outside the main progression.

Geometry examples: [flowchart](../assets/example-flowchart.html). These retain an upstream illustration palette; use [design defaults](design.md) for new work.
