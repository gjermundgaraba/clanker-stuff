# Kanban

Work items grouped by current state.

Columns represent workflow states and cards represent work items at the snapshot time. Counts reconcile with displayed items plus explicitly identified collapsed groups. Show WIP limits only when supplied, distinguishing absent limits from zero; compare count against the actual limit. Mark every blocked/waiting item consistently even when several need emphasis. Arrows are usually unnecessary because column membership carries state; detailed handoffs belong in a process view. Retain owners and ticket identifiers when they matter to the requested scope.

Geometry examples: [kanban](../assets/example-kanban.html). These retain an upstream illustration palette; use [design defaults](design.md) for new work.
