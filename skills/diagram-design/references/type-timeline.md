# Timeline

Dated events and milestones.

Map time to position using a shared scale: `x(t)=L+W*(t-t0)/(t1-t0)`. Unequal intervals produce unequal spacing. For an intentionally schematic ordered sequence, say that spacing is not elapsed time. Use leaders and alternate label bands to handle clustered dates; do not move event markers. Axis breaks need visible markings and explicit skipped intervals. Distinguish points from duration spans and actual dates from forecasts.
