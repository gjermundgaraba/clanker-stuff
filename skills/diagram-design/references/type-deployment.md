# Deployment

Runtime placement and infrastructure boundaries.

Place deployed artifacts inside their actual host, container, cluster, region, or network zone. Show nested boundaries only when their containment is real. Label network paths with relevant protocol/port and identify external systems. Replication, asynchronous transport, and request paths need distinct defined treatments. A connection crossing a security boundary does not by itself establish authorization. Avoid implying high availability from a single representative instance unless replicas/counts are stated.
