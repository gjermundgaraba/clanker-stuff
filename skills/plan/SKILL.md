---
name: plan
description: Clarify ambiguities, assumptions, and open questions with the user before work that depends on them. Use when the user asks to plan, scope, or talk a task through before implementing, asks to be asked questions first, or names this skill in a prompt, brief, or pasted text such as `/plan` or `$plan`. Not for interrupting a clearly specified task with questions.
---

Resolve discoverable facts through targeted inspection of available context.
Ask the user about remaining ambiguities, important assumptions, and open
questions that could affect the goal, success criteria, scope, constraints,
or approach.

Before asking, tell the user in plain text what the inspection found and,
for each question, why it matters and what the options trade off, so each
question can be answered from what they have already read. If an answer
asks for more context, explain in text and wait before asking again.

Use a question tool when available and permitted; otherwise, provide a
concise numbered list. Where useful, offer meaningful options and recommend
one.

Wait for answers before proceeding with work that depends on them.
Ask follow-up questions until consequential ambiguities are resolved.
If nothing needs clarification, say so.
