# footer

Replaces the pi footer with a compact context gauge, git status, and subscription usage bars for the active provider.

## Install

```bash
pi install npm:@clanker-extensions/footer
```

## Usage

The footer loads automatically in interactive sessions. Run `/usage` to display provider usage, or `/usage refresh` to bypass cached values.

## Configuration

See [provider support and credential handling](docs/providers.md) before enabling usage data.
