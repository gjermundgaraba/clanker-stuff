# voice

Adds Codex-style realtime voice conversations backed by the current pi session.

> [!CAUTION] **Experimental:** This is not a stable daily driver. Breaking changes may happen without notice, and the extension may be removed.

## Install

Load `pi/extensions/experimental/voice/index.ts` as a local extension; npm installation is not supported.

## Usage

Run `/voice` to start or stop voice; click the orb to pause, or ask the assistant to end the voice chat.

## Requirements

macOS arm64, ChatGPT.app, microphone access, and an OpenAI Codex OAuth login in pi.
