# shape-spinner

Replaces Pi's working spinner with selectable Rubik's cube or wireframe shape animations.

> [!CAUTION] **Experimental:** This is not a stable daily driver. Breaking changes may happen without notice, and the extension may be removed.

## Install

Install the bundled font using the [setup instructions](docs/setup.md), then run `pi install ./pi/extensions/experimental/shape-spinner` from this repository.

## Usage

- An orb animates while Pi works, inked for your theme's light or dark background.
- Run `/shape-spinner` to open the settings dialog: pick the shape, color, and playback, with an animated preview that applies live and also verifies the font.

## Requirements

Pi 1.0 or newer, Ghostty on macOS, and the bundled color font installed on the display machine; disable other working-spinner extensions. See [setup and compatibility](docs/setup.md).
