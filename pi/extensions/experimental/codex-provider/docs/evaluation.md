# Harness evaluation

Provider-local evaluation scripts were replaced by the repository's
[Harbor eval tooling](../../../../evals/README.md).

Compare **Pi without Code Mode**, **Pi with Code Mode**, and **native Codex**.
Frontier Qubit Routing provides a released coding task and continuous upstream
scores; ledger scaling is a small API-only mechanism diagnostic. Both runners
resolve the latest published native Codex when preparing a new series, freeze
its version and images, and require a no-model preflight before paid trials.

The eval-only wrapper overrides Astra's required tool mode for the direct arm.
Normal provider behavior is unchanged. See the Harbor instructions for setup,
commands, validity checks, limitations, and verified results.
