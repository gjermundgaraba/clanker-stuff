# tools

Adapts pi's coding tools to model-native interfaces and adds /tools for choosing active tools.

> [!CAUTION] **Experimental:** This is not a stable daily driver. Breaking changes may happen without notice, and the extension may be removed.

## Install

Load `pi/extensions/experimental/tools/index.ts` as a local extension; npm installation is not supported.

## Usage

Run `/tools` to choose active tools; model-native profiles activate automatically.
