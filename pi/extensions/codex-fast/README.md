# codex-fast

Adds /fast to toggle OpenAI Codex fast mode and shows a lightning status while active.

## Install

```bash
pi install npm:@clanker-stuff/codex-fast
```

## Usage

Fast mode starts disabled; run `/fast` to toggle it, or start pi with `--fast` to enable it, for supported OpenAI Codex models.

## Requirements

A ChatGPT account with Codex fast-mode access.
