# tones

Shares semantic color tones and status ramps across Pi extensions.

## Install

```bash
npm install @clanker-stuff/pi-tones
```

## Usage

Use `ToneSchema` and `percentTone(percent)` so status surfaces share one tone vocabulary and one usage ramp. Tone meanings are defined in the [color conventions](https://github.com/gjermundgaraba/clanker-stuff/blob/main/docs/color.md).
