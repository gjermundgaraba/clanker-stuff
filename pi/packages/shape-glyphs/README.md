# shape-glyphs

Shares Shape Spinner's font glyphs so Pi extensions can draw its spinning shapes as text.

## Install

```bash
npm install @clanker-stuff/pi-shape-glyphs
```

## Usage

Draw `wireframe(shape, ink, background).frames` or `RUBIK.frames` one per `FRAME_INTERVAL_MS`; the glyphs render only where the [shape-spinner](https://github.com/gjermundgaraba/clanker-stuff/tree/main/pi/extensions/experimental/shape-spinner) font is installed, which its `/shape-spinner` command (`SHAPE_SPINNER_COMMAND`) shows.
